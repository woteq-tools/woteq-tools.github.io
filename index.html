Why they're different

A few rules every tool here follows.

Your files stay yours

Everything is processed with JavaScript in your own browser. No uploads, no servers holding your data.

Instant, no build step

Every tool is a static page served straight from GitHub Pages. It opens fast and works offline once loaded.

Open source

Each tool links straight to its repository. Read it, fork it, change it, ship it.
